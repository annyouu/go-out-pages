go out プライバシーポリシー

最終更新日: 2026年8月17日

go out（以下「本アプリ」といいます）は、ユーザーが選択したアプリやWebサイトへのアクセスを一定時間制限し、 設定した目的地への外出をきっかけとして、スマートフォンの使い方や日々の行動を見直すことを支援するiPhoneアプリです。

本アプリの開発者（以下「開発者」といいます）は、本アプリにおけるユーザーの情報およびプライバシーの取扱いについて、 以下のとおりプライバシーポリシー（以下「本ポリシー」といいます）を定めます。

第1条　基本方針

本アプリは、機能の提供に必要な情報を可能な限りユーザーの端末上で処理する方針としています。

現在のバージョンでは、本アプリが利用する位置情報、目的地情報、Family Controls / Screen Timeに関する情報を、 開発者が運営する外部サーバーへ送信していません。

また、現在のバージョンでは、ユーザー登録やアカウント作成を必要とせず、広告配信またはユーザー行動分析を目的とした外部SDKを利用していません。

第2条　端末上で利用・保存する情報

本アプリでは、機能を提供するため、以下の情報をユーザーの端末上で利用または保存する場合があります。

（1）Family Controls / Screen Timeに関する情報

本アプリでは、Appleが提供するFamily Controls / Screen Timeの機能を利用し、ユーザー自身がブロック対象として選択したアプリやWebサイトに関する情報を端末上で利用します。

これらの情報は、ユーザーが設定した時間帯に、選択したアプリやWebサイトへのアクセスを制限するために使用します。

現在のバージョンでは、これらの情報を開発者が運営する外部サーバーへ送信していません。

（2）位置情報

本アプリでは、端末の位置情報機能を利用して、ユーザーの現在位置を取得する場合があります。

位置情報は、以下の目的で利用します。

  • 地図上に現在地を表示するため
  • 現在地と設定した目的地との距離を確認するため
  • ユーザーが目的地付近に到着しているかを判定するため
  • 目的地付近でブロックを解除できるかを判定するため

現在のバージョンでは、ユーザーの継続的な移動経路や正確な移動履歴を作成・保存することを目的として位置情報を利用していません。

また、本アプリの開発者が運営する外部サーバーへユーザーの現在位置を送信していません。

（3）目的地および設定に関する情報

本アプリでは、ユーザーが作成した目的地やブロック設定を管理するため、以下の情報を端末上に保存する場合があります。

  • 目的地の位置情報
  • 目的地に関する表示情報
  • 設定した日付
  • ブロックする時間帯
  • ブロック対象に関する設定情報
  • ブロックの状態
  • 解除の状態
  • その他、本アプリの機能提供に必要な設定情報

これらの情報は、本アプリ内で目的地、ブロック状態および利用履歴等を表示・管理するために使用します。

現在のバージョンでは、これらの情報を開発者が運営する外部サーバーへ送信していません。

第3条　本アプリが取得・閲覧しない情報

本アプリは、Family Controls / Screen Timeを利用してアプリやWebサイトへのアクセスを制限しますが、以下の内容を取得または閲覧するものではありません。

  • SNSへの投稿内容
  • DMやチャット等のメッセージ内容
  • メールの内容
  • Webサイト上で閲覧したページの内容
  • Webサイトへの入力内容
  • ブラウザで閲覧した具体的なコンテンツ
  • 写真や動画の内容
  • 連絡先
  • 通話内容
  • ユーザーの継続的な移動経路
  • 正確な移動履歴

本アプリは、ブロック対象としてユーザーが選択したアプリやWebサイトの内部コンテンツを取得または監視するものではありません。

第4条　情報の利用目的

本アプリが端末上で利用する情報は、主に以下の目的で利用します。

  • ユーザーが選択したアプリやWebサイトへのアクセスを制限するため
  • 地図上に現在地および目的地を表示するため
  • 現在地と目的地との距離を判定するため
  • 目的地付近でブロックを解除できるかを判定するため
  • ユーザーが設定した目的地、日時、ブロック状態等を本アプリ内で管理・表示するため
  • 本アプリの機能を提供するため

これらの情報を、広告配信、ユーザーの追跡またはデータ販売を目的として利用することはありません。

第5条　外部への情報送信

現在のバージョンでは、以下の情報を開発者が運営する外部サーバーへ送信していません。

  • ユーザーの現在位置
  • 継続的な移動履歴
  • 作成した目的地
  • Family Controls / Screen Timeを利用して選択したアプリやWebサイトに関する情報
  • ブロックおよび解除に関する設定情報

これらの機能に必要な処理は、原則としてユーザーの端末上で行われます。

また、現在のバージョンでは、広告配信、アクセス解析またはクラッシュ解析等を目的としてユーザーデータを収集する外部SDKを導入していません。

ただし、本アプリが利用するiOS、App Store、地図機能その他Appleが提供するサービスについては、Appleのサービスを提供するために必要な情報がAppleによって処理される場合があります。 これらの情報の取扱いについては、Appleが定めるプライバシーポリシーその他の条件が適用されます。

第6条　第三者への提供

開発者は、本アプリを通じて開発者が取得したユーザーの個人情報を、本人の同意なく第三者に販売または提供しません。

ただし、以下の場合を除きます。

  • ユーザー本人の同意がある場合
  • 法令に基づき開示が必要となる場合
  • 人の生命、身体または財産の保護のために必要があり、本人の同意を得ることが困難な場合
  • その他、法令上認められる場合

なお、現在のバージョンでは、本アプリが端末上で利用する位置情報、目的地情報、Family Controls / Screen Timeに関する情報を、 開発者が運営する外部サーバーに収集していません。

第7条　端末上のデータの保存および削除

本アプリで作成した目的地や各種設定情報は、主にユーザーの端末上に保存されます。

本アプリ内では、機能の性質上、すべての目的地情報をいつでも削除できるわけではありません。

現在の仕様では、以下のように取り扱います。

  • 作成途中のピンは削除できます
  • 未来の日付に作成した予約ピンは削除できます
  • 当日のブロックに使用しているピンは、ブロックを回避する手段として削除機能が利用されないよう、削除できません
  • 過去の日付のピンは利用履歴として扱うため、現在のバージョンでは削除できません

これらの仕様は、本アプリのアップデート等により変更される場合があります。

本アプリを端末から削除した場合、本アプリが端末内に保存しているデータについては、iOSの仕組みに従って削除されます。

第8条　位置情報について

位置情報は、GPS、Wi-Fi、携帯電話ネットワーク、建物、周辺環境、端末の状態その他の要因によって誤差が生じる場合があります。

そのため、本アプリに表示される現在地、目的地との距離または到着判定が、常に実際の位置と完全に一致することを保証するものではありません。

本アプリは、目的地への継続的な移動経路を記録することを目的として位置情報を利用するものではありません。

位置情報の利用を許可しない場合、本アプリの地図表示、距離判定、目的地付近での解除等、一部または全部の機能を利用できない場合があります。

第9条　ユーザーによる権限の管理

ユーザーは、iPhoneの設定から、本アプリに対して許可した位置情報その他の権限を確認または変更することができます。

権限を無効にした場合、本アプリの一部または全部の機能が正常に利用できなくなる場合があります。

Family Controls / Screen Timeに関する権限についても、iOSが提供する仕組みに従って管理されます。

第10条　お問い合わせ時に提供される情報

本アプリに関するお問い合わせをメールで行った場合、ユーザーがメール内で提供した以下のような情報を、問い合わせへの対応に必要な範囲で取り扱う場合があります。

  • メールアドレス
  • お問い合わせ内容
  • ユーザーが任意で提供した端末情報、iOSバージョン、スクリーンショットその他の情報

これらの情報は、問い合わせへの回答、不具合の確認および必要なサポートを行うために利用します。

お問い合わせによって提供された情報は、対応に必要な期間および法令上必要な期間に限り適切に管理します。

第11条　安全管理

開発者は、開発者が取り扱うユーザーの情報について、不正アクセス、漏えい、滅失または毀損等を防止するため、利用状況および情報の性質に応じた合理的な安全管理に努めます。

本アプリの主要な設定情報については、現在のバージョンでは原則として端末上で処理・保存し、不要な外部送信を行わない設計としています。

第12条　ユーザーの権利

現在のバージョンでは、本アプリの主要な利用データはユーザーの端末上に保存されており、開発者のサーバーには保存されていません。 そのため、開発者はこれらのデータを確認、変更または削除することができません。

端末上のデータについては、本アプリ内で提供される削除機能または本アプリの削除等により、ユーザー自身で管理することができます。 ただし、本アプリの機能上、一部のピンは削除できない場合があります。

なお、お問い合わせメールを通じてユーザーから提供されたメールアドレスやお問い合わせ内容については、サポート対応に必要な範囲で取り扱います。

第13条　外部サービスおよび将来の機能変更

今後、本アプリにアカウント機能、クラウド同期、アクセス解析、クラッシュ解析、通知、有料機能その他現在のバージョンに含まれていない機能を追加する場合があります。

これらの機能追加により情報の取扱いが変更される場合は、必要に応じて本ポリシーおよびApp Store上のプライバシー情報を更新します。

重要な変更がある場合には、本アプリまたは関連ページ等を通じて適切な方法で案内します。

第14条　本ポリシーの変更

開発者は、本アプリの機能変更、サービス内容の変更、法令の変更その他必要な事情に応じて、本ポリシーを変更する場合があります。

変更後のプライバシーポリシーは、本ページに掲載した時点または別途定めた時点から適用されます。

重要な変更がある場合には、本アプリまたは関連ページ等を通じて適切な方法で案内します。
